INSTALL

四步装好，打开 BOSS 就能用。

这是未上架商店的开发版扩展，需要用“加载已解压的扩展程序”安装。压缩包解压后请保留文件夹位置。

  1. 01

    下载并解压

    下载 BossHunter.zip，解压到一个固定目录。移动或删除该目录后，扩展会失效。

    下载最新压缩包 ↘
  2. 02

    打开扩展管理页

    用右侧助手复制对应浏览器的扩展页地址，粘贴到地址栏回车。Chrome 是 chrome://extensions，Edge 是 edge://extensions。

  3. 03

    开启开发者模式并加载

    打开右上角“开发者模式”，点“加载已解压的扩展程序”，选择刚才解压出来的文件夹。

  4. 04

    打开职位列表页

    访问 BOSS 直聘职位列表页，点右下角 BH 展开面板；在“设置”里配置条件，保存并筛选后即可预览和投递。

为什么不能自动跳转？

这是浏览器的安全限制：如果网页能随意打开扩展管理、设置等内部页面，任意网站都可能诱导你修改敏感设置。因此网页只能复制地址，不能代替你跳转。

为什么不能一键打开 chrome://extensions？

浏览器不允许普通网页跳转到内部页面，chrome://、edge://、brave:// 都属于这一类。页面提供“复制地址”按钮，粘贴到地址栏回车是最快的方式。

下载后怎么安装？

先解压 zip，再打开扩展管理页，开启“开发者模式”，点“加载已解压的扩展程序”，选择解压后的文件夹。不要直接选择 zip 文件。

支持 Edge 吗？

支持 Edge、Brave、Opera、Vivaldi 等 Chromium 内核浏览器。扩展页地址不同，可以在安装区切换浏览器并复制对应地址。Firefox 未验证。

为什么下载的是 zip，不是 crx？

Chrome 商店之外的 crx 安装会受到限制，而开发版扩展用 zip 解压后“加载已解压的扩展程序”更稳定，也方便查看源码。

会上传我的数据吗？

不会。配置和运行状态保存在浏览器本地的 chrome.storage.local 中，项目没有账号系统，也没有收集数据的服务端。

使用自动化投递会被封号吗？

任何自动化操作都有账号风控风险。项目内置了投递间隔下限，但仍请遵守 BOSS 直聘的服务条款，合理、适度使用，并自行承担相关风险。
